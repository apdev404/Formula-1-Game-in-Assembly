# Formula-1-Game-in-Assembly 🚗🏁

## Descripción 🎮

Juego ambientado en **Formula 1**, realizado en **Assembler**. El juego está diseñado en el lenguaje de máquina Assembler y se ejecuta a través de la máquina virtual **DOSBox**.

## Instrucciones de Ejecución ⚙️

### Requisitos previos 📝

1. **Instalar DOSBox**: Asegúrate de tener **DOSBox** instalado en tu máquina para poder ejecutar el juego.
2. **Ubicación de los Archivos**: Debes tener guardado el juego en la carpeta **TASM**.

### Pasos para ejecutar el juego 🏁

1. **Abrir DOSBox**: Inicia DOSBox y navega hasta la carpeta donde tienes los archivos del juego.

2. **Ejecutar el juego**:
   - En la terminal de DOSBox, escribe el siguiente comando para iniciar el juego:

     ```bash
     i intgraf F1
     ```

   - Una vez ingresado el comando, verás la pantalla de inicio del juego.

   ![Pantalla de inicio](https://drive.google.com/uc?export=view&id=1rrP5hgmVnppwX-pc5HypiYeRAdoEiYyU)

3. **Pantalla de bienvenida**: Después de iniciar el juego, aparecerá un menú inicial. Presiona cualquier tecla para continuar.

   ![Menú de inicio](https://drive.google.com/uc?export=view&id=1wz2lX_RA8Z8oTyvAYoFgMIZTKZeZYP58)

4. **Menú de opciones**: A continuación, verás un menú donde podrás ver las opciones de controles y una opción para empezar a jugar directamente.

   ![Menú de opciones](https://drive.google.com/uc?export=view&id=1bw7OKss8K01sQsOCjp5r3YOmzhqZf85Y)

5. **Controles**: En el menú de controles, encontrarás las instrucciones para manejar el juego.

   ![Controles del juego](https://drive.google.com/uc?export=view&id=11wYnjCtes36pubH1wkJDeHZSCqNapHkK)
